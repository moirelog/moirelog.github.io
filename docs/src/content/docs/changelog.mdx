记录 Moire 仓库和快捷指令的更新历史。


## Shortcuts 版本

### v1.0.1 (2026-02-15)

**改进**：
- 使用 utc 时间
- 支持 todo list
- 支持 monospace -> code
- 支持 `order_by` 配置：按创建时间或修改时间排序

**下载**：
- [Moire v1.0.1](/v1.0.1/shortcuts.json)

---

### v1.0.0 (2026-02-07)

**首次发布**：

- 基础同步功能
- Markdown 文本上传
- 支持自定义 API Base URL
- 支持图片上传（每篇 1 张）
- 优化网络超时处理
- 改进错误提示信息

**下载**：
- [Moire v1.0.0](/v1.0.0/shortcuts.json)

## 即将推出

### 短期计划（1-2 个月）

-  **Markdown 语法**：支持更多 Markdown 语法
-  **笔记卡片**：生成卡片，优化分享展示
-  **流程优化**：集成 github auth，简化部署流程

### 中期计划（3-6 个月）

-  **评论系统**：集成 Giscus 或其他评论系统
-  **访问链接**：支持单条笔记的访问链接
-  **多图片上传**：支持每篇笔记 3-5 张图片


### 长期愿景

- 🔮 **多来源支持**：支持 Telegram Channel 或其他来源
- 🔮 **在线编辑器**：Web 版笔记编辑
